# Worksheet — ระบบเลือกตั้ง (ระบบอ้างอิง)

Boundary: **U** = Unit · **I** = Integration · **C** = Component · **K** = Contract · **E** = End-to-end · **X** = ไม่ใช่ automated functional test

| # | Test case | Boundary | เหตุผล |
|---|---|---|---|
| 1 | เลขบัตรประชาชนที่ checksum ผิด ถูกปฏิเสธตอนลงทะเบียน | U | เช็คแค่ function isValidThaiNationalId ไม่ต้องใช้ db หรือ HTTP |
| 2 | ลงทะเบียนด้วยเขตเลือกตั้งที่ไม่มีในระบบ ได้ 400 | C | logic อยู่ใน service เทสแบบ U ได้ แต่ต้องมี C อย่างน้อย 1 ข้อเพื่อดูว่าได้ 400 จริง |
| 3 | `PgUserRepository.findByNationalId` คืน user ที่ map column → field ถูกต้อง | I | ต้องเทส repo กับ postgres จริงถึงจะรู้ว่า map column ถูก |
| 4 | ผู้มีสิทธิเลือกตั้ง (VOTER) เรียก `POST /parties` แล้วได้ 403 | C | เทส middleware แบบ U ได้ แต่ C จำเป็น เพราะต้องดูว่าผูก middleware กับ route ถูก |
| 5 | ผู้ใช้ลงทะเบียน → login → ลงคะแนน → เปลี่ยนคะแนน → กกต. ปิดหีบ → ผลแสดงคะแนนถูกต้อง | E | เป็น flow ยาวของ user หลายขั้นทั้งระบบ ควรมีแค่ไม่กี่ข้อ |
| 6 | รหัสผ่านถูกเก็บแบบ hash ไม่ใช่ plain text | U | เทส hashPassword ได้เลยว่าผลไม่ใช่ plain text เทสแบบ I ดูใน db ด้วยก็ได้แต่ไม่จำเป็น |
| 7 | หมายเลขผู้สมัครในเขตเดียวกันห้ามซ้ำ | U | service เช็คหมายเลขซ้ำอยู่แล้ว เทสด้วย repo ที่ไม่ต่อ db ได้ ส่วน UNIQUE ใน db เทสแบบ I ได้แต่ไม่จำเป็นมาก มีไว้กันกรณีส่งพร้อมกัน |
| 8 | Liquibase changelog ทั้งหมด apply บน database เปล่าได้สำเร็จ | I | ต้องรัน liquibase กับ db เปล่าจริง ซึ่ง CI ทำทุกครั้งอยู่แล้วตอน db:migrate:test |
| 9 | ก่อนปิดหีบ `GET /districts/:id/results` ไม่แสดงคะแนน | C | ต้องยิง GET /districts/:id/results แล้วดูว่าไม่มีคะแนน |
| 10 | Frontend คาดว่า results API มี field `closed` และ `candidates[].votes` | K | เป็นเรื่องที่ frontend กับ API ต้องตกลงรูปร่างข้อมูลกัน |
| 11 | JWT ที่หมดอายุแล้ว ใช้ยืนยันตัวตนไม่ได้ | U | เทส TokenService กับ token ที่หมดอายุได้เลย เทสแบบ C ว่าได้ 401 ก็ได้แต่ไม่จำเป็น |
| 12 | admin เปลี่ยน role ผู้ใช้เป็น กกต. แล้วผู้ใช้นั้นสร้างพรรคได้ | C | ยิง HTTP หลายครั้งใน app เดียวได้ (เปลี่ยน role แล้วสร้างพรรค) ไม่จำเป็นต้องถึง E |
| 13 | ระบบรับการลงคะแนนพร้อมกัน 1,000 ครั้งในนาทีแรกหลังเปิดหีบได้ | X | เป็นเรื่อง performance ต้องทำ load test แยก เช่นใช้ k6 |
